# GitDesk

A lightweight, native macOS Git client with a GitKraken-style layout — just the features needed day to day, without the subscription.

Built with Swift and SwiftUI. It drives your own `git` install, so SSH keys, the macOS Keychain credential helper and your global git config all work exactly as they do in the terminal.

## Features

- **GitKraken-style layout** — repo/branch switchers and Pull · Push · Fetch · Branch · Stash · Pop across the top, refs on the left, commit graph in the middle, staging/commit panel on the right.
- **All your repositories in one list** — add them one by one, or **scan a folder** to find every repo inside it. Each shows its branch, uncommitted changes and ↓behind / ↑ahead counts.
- **Pull All** — fast-forward pulls every repository at once (four at a time), with a per-repo result on the *All Repositories* screen. It uses `--ff-only`, so it never creates merge commits or conflicts; anything that has diverged is flagged for you to deal with.
- **Amend / squash into the previous commit** — toggle *Amend previous commit* when committing a second time. If that commit has already been pushed, GitDesk pushes with `--force-with-lease` automatically (safe: it refuses if someone else pushed in the meantime). You can also right-click HEAD → *Squash into Previous Commit*.
- **Reuse the last commit message** — *Reuse message* fills in the last commit's message in this repo, or any message you've recently used in **any** repo (handy for using the same task ID across several repos). Turning on amend pre-fills it too.
- **Clone Repository** — paste a URL, choose a folder (defaults to `~/Sites`).
- **⌘P command palette** — fuzzy search over every action, repository and branch.
- Commit graph with branch/tag labels, commit details, file diffs with line numbers, stage/unstage/discard per file, stashes, branch checkout/create/merge/delete, cherry-pick, revert and soft/mixed reset.

## Building

Requires macOS 14+ and Xcode (or the Swift toolchain).

```sh
./scripts/build-app.sh            # builds build/GitDesk.app
./scripts/build-app.sh --install  # also copies it to /Applications
```

For development, `swift run` launches it straight from the package.

The app icon is generated by `swift scripts/make-icon.swift` (already committed as `Resources/AppIcon.icns`).

### Debug-only helpers

Debug builds (`swift build`) include two development aids that are compiled out of release builds:

- `GITDESK_SNAPSHOT=/tmp/shot.png swift run` — saves a PNG of the window after a few seconds, then quits.
- `GITDESK_SELFTEST=/path/to/throwaway/clone swift run` — scripts commit, push, amend + force-push, squash, stash, branch and Pull All against the given clone and prints PASS/FAIL. **Only point it at a disposable clone** — it commits and force-pushes.

## Data

The repository list is stored in `~/Library/Application Support/GitDesk/repositories.json`. Removing a repository from the list never touches the files on disk.
